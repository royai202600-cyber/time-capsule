# SOP: Running a private hunt

Private hunts use the organizer tools described in [City Orienteering](../design/city-orienteering.md). During the pilot, access to create hunts comes from `profiles.can_create_hunts`.

1. Open **My Hunts** and create a draft with a name, a start and end, a route order and leaderboard visibility. Add a time limit if each player should have a shorter window.
2. Place each quest on the map. Choose a template picture or upload a photo. Select Arrive, Spin or Puzzle and set the points. For Arrive with GPS + QR, save the quest before printing its QR code for the waypoint. Test the printed code before sharing the hunt.
3. Publish and share the join code, link or QR. Players can join before the start. The first join locks route order, timing and quests, so confirm those details before sharing.
4. During the hunt, use Review for participant progress, quest completion and ranking. Players receive a private Passport stamp after finishing every quest.
5. When verifying a release, use separate disposable organizer and player accounts. Check that the player can open signed quest photos and that the server rejects wrong QR codes, wrong puzzle answers and locked organizer edits. Remove uploaded test photos through Storage before deleting the disposable accounts.
